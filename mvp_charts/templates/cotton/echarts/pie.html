{# @description A pie chart: part-to-whole at a glance, for a handful of parts, with the tail folded together. #} {# @strict #} {# @prop name:text | required | description:"Accessible name — what a screen reader announces this chart as" #} {# @prop description:text | required | description:"Text alternative — what the chart shows, for anyone who cannot see it" #} {# @prop labels:text | description:"What the slices are called. A comma-separated list, or a Python sequence passed with a colon" #} {# @prop values:text | description:"The slice sizes, in the same order as labels" #} {# @prop :series:text | description:"The same thing written the long way: a single series whose data are the slice sizes" #} {# @prop slices:number | description:"How many slices to draw before the rest are folded into one. Defaults to 6, the point past which slices stop being tellable apart" #} {# @prop :config:text | description:"An object carrying any of these same attributes, built in Python. An attribute written on the tag wins over the same key here" #} {# @prop :options:text | description:"Raw ECharts options, deep-merged over everything the component built. A donut is radius: ['45%', '62%'] here" #} {# @prop empty:text | description:"What to say when there is nothing to draw. Defaults to a translated message" #} {# @prop renderer:select['canvas', 'svg'] | description:"Which ECharts renderer draws this chart. Defaults to canvas" #} {# @prop id:text | description:"Element id. Assigned per request when omitted" #} {% comment %} Slices are sorted largest first and labelled on the chart, so a pie carries no legend: its identity is already beside each slice. Every attribute is declared with an empty default on purpose: a component's own default must not beat a config object the author actually wrote, and Cotton cannot tell an absent attribute from one written empty. The defaults live in mvp_charts.echarts.options instead. {% endcomment %} {% load mvp_charts %} {% echarts_chart "pie" name=name description=description labels=labels values=values series=series slices=slices config=config options=options empty=empty renderer=renderer id=id as chart %} {% if chart.name and chart.description %}{{ chart.script }}{% endif %}
