Every attribute is declared with an empty default on purpose: a component's own default must not beat a config object the author actually wrote, and Cotton cannot tell an absent attribute from one written empty. The defaults live in mvp_charts.echarts.options instead. {% endcomment %} {% load mvp_charts %} {% echarts_chart "pie" name=name description=description labels=labels values=values series=series config=config options=options id=id as chart %} {% if chart.name and chart.description %}{{ chart.script }}{% endif %}
