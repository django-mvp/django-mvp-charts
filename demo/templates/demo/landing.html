django-mvp-charts

Charts as Cotton components. This page is where they get looked at while they are being built.

Nothing to see yet

The package is scaffolded and the test harness is green, but no components have been written. The first ones will appear under the echarts namespace as <c-echarts.line /> and friends, each rendered here as it lands.

How the JavaScript arrives

This page will load Apache ECharts from a CDN, which is the right trade for a demonstration and for local development. Projects using the package in production are expected to bundle it themselves, importing only the chart types and renderers they actually use. Nothing is vendored into this repository.
