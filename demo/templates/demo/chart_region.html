It fills that element exactly and has no height of its own, so the wrapper below carries one and the region takes it. Only the id is required. It is what the caption and the drawing surface are tied to, so a screen reader reads the right description for the right chart, and it is never filled in for you: an id this package invented would change under you the moment the page put a second chart above it. The name is what the chart is announced as and the description is what it says the chart shows. Both are optional, and both are worth giving — a chart drawn into a canvas is invisible to anyone who cannot see it, so leaving them out is a choice rather than a shortcut. {% comment %} cotton:verbatim is required, not decoration: without it Cotton compiles the markup before show_code can capture it, and the source pane comes out empty. {% endcomment %} {% show_code %} {% cotton:verbatim %}

It is empty because a region on its own is the space a chart draws into, not a chart — see the line chart page for one that draws. Each region is its own, whatever size it is given. They take four different heights here, and none of them knows the others exist.
Three things stop a region working, and all three look the same on screen: an empty box, no error, nothing to act on. So none of them is left as one. Each says what is wrong, in the page, where the chart would have been.

No height to fill

The element around it resolved to nothing, usually a percentage height inside an ancestor sized by its own content. {% comment %} The wrapper asks for a percentage of an ancestor that is sized by its own content, so it resolves to nothing. `items-start` on the grid above is what keeps that true: a stretched grid cell has a definite height, and the percentage would resolve against it. {% endcomment %}

No id

The id is the author's to give and the package invents none, because a caption has to point at the region it describes.

No charting library

Framed from a document of its own, because the check reads a global and so applies to a whole page. Takes a few seconds: a bundle still loading is an ordinary project, so the region waits before it judges.
