It fills that element exactly and has no height of its own, so the wrapper below carries one and the region takes it. The name and the description are both required. The name is what a screen reader announces the chart as, and the description is what it says the chart shows — neither is optional, because a chart drawn into a canvas is invisible without them. {% comment %} cotton:verbatim is required, not decoration: without it Cotton compiles the markup before show_code can capture it, and the source pane comes out empty. {% endcomment %} {% show_code %} {% cotton:verbatim %}

A region put in an element with no resolved height gets none itself, and a chart with no height is a blank rectangle nobody can diagnose.
