All three scripts are loaded here, by this project. None comes from the package, which supplies no script tag of any kind. ECharts first, from a public copy, which is what a project does while it has no build step. The version is pinned and carries an integrity hash, so the browser refuses the file if it is not the one it was expected to be. `crossorigin` is not decoration: a browser only checks integrity on a cross-origin request made in CORS mode, so without it the hash is never verified while still looking as though it is. A project that builds its own bundle drops this line and exposes the library as window.echarts instead. Then the package's own two modules: chart-region.js, which every region needs in the browser, and echarts-chart.js, which draws a line chart from its region once it is ready. A demo whose every page shows a chart puts both in the base template.
